# MySound Relay

Телефон 1 (отправитель) захватывает системный звук и по Wi-Fi шлёт его на телефон 2 (приёмник).
Приёмник играет звук в текущий аудиовыход — в том числе в Bluetooth-колонку.

## Сборка
1. Android Studio -> File -> Open -> папка MySoundRelay. Дождаться Gradle Sync
   (если спросит про Gradle wrapper / версию — согласиться).
2. Build -> Build APK(s) или запуск на телефоне кабелем.
3. Установить на ОБА телефона.

## Использование
1. Оба телефона в одной Wi-Fi сети.
2. Телефон 2: подключить к колонке по Bluetooth, нажать «Включить приёмник».
3. Телефон 1: нажать «Найти приёмник» (или ввести IP вручную), «Начать отправку»,
   разрешить захват звука, запустить музыку (Яндекс Музыка и т.д.).

## Как это работает
Звук идёт по UDP пакетами по 5 мс (48 кГц, стерео, 16 бит). Нет очереди и повторных отправок,
поэтому задержка не копится. На приёмнике пакеты попадают в джиттер-буфер: он выравнивает
неровности Wi-Fi, заменяет потерянный пакет тишиной и сбрасывает лишнее, если буфер переполнился.
Оба телефона держат Wi-Fi в режиме низкой задержки (WifiLock) и не дают CPU уснуть.

## Синхронизация колонок
Колонка 1 (на телефоне 1) играет напрямую от музыкального приложения, поэтому приложение
не может её задержать. Вместо этого минимизируется задержка колонки 2:
на телефоне 2 есть ползунок «Буфер приёмника» (10–500 мс, по умолчанию 60), он работает на лету.
Двигай его влево, пока колонки не зазвучат одновременно; если появились провалы — вправо.

Строка статуса под кнопками помогает понять причину:
- «потеряно» или «опустошений» растут — Wi-Fi не справляется, увеличь буфер;
- «сброшено» растёт — приходит больше, чем играется, это нормально раз в минуты;
- всё чисто, а задержка есть — её даёт Bluetooth-кодек колонки 2, а не приложение.

## Ограничения
- Захват работает с Android 10+ и только для приложений, которые не запретили его
  (allowAudioPlaybackCapture=false) и не защищают контент DRM. Если слышна тишина —
  это обычно оно.
- Задержка около 0.3–1 с, для видео не подойдёт.
- Wi-Fi с «изоляцией клиентов» (гостевые сети) блокирует связь между телефонами.

## Сборка APK онлайн (без Android Studio)
1. Зарегистрироваться на github.com, нажать «+» -> New repository, имя любое, Create.
2. На странице репозитория: «uploading an existing file», перетащить ВСЁ содержимое папки
   MySoundRelay (включая скрытую папку .github), Commit changes.
3. Вкладка Actions -> «Build APK» -> дождаться зелёной галочки (3–6 минут).
4. Открыть завершённую сборку -> внизу Artifacts -> MySoundRelay-apk -> скачать zip, внутри app-debug.apk.
